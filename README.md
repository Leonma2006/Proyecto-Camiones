# Proyecto Camiones
El sistema tiene para poder conectarse con un servidor de sql lite mediante red local, simplemente asigandole el puerto, servidor, nombre de la base de datos, y se debe crear un usuario de sql para poder entrar.

Tambien contiene la opcion de conectarse al archivo directo de sql, se incluira un respaldo tipo .bak y se debe respaldar desde sql server managment para que funcione, de igual forma se dejaran las especificaciones para crear desde 0 una nueva base de datos propia en su dispositivo.
